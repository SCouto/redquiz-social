# redquiz-social

Rendered post images for the RedQuiz Instagram accounts.

This repo is public for one reason: the Instagram Content Publishing API takes an
`image_url` and fetches it from Meta's own servers — there is no binary upload for
feed images. The pictures have to be anonymously reachable over HTTPS.

Nothing here is written by hand. Files under `img/` are generated by
`redquiz/social/scripts/render.py` in the (private) app monorepo and pushed by the
`social-post` workflow. Images are served straight from
`raw.githubusercontent.com`; no GitHub Pages involved.
